# scrn-flow-compare — сравнение сценариев из Screen Gallery

Скилл для ИИ-агента (Claude, Codex и других, кто понимает формат SKILL.md): находит в каталоге Screen Gallery нужный сценарий у разных приложений (или у одного приложения в разных версиях), сравнивает по шагам как UX-аналитик и собирает результат в нужном формате:

- отчёт прямо в чате — со ссылками на сценарии и экраны;
- PDF — обложка, таблица «кто что умеет», страница на каждую находку со скринами и кнопкой «Сценарий в SCRN», итог;
- те же страницы отчёта картинками (JPG, горизонтальные, без кнопок) — для альбома в посте или презентации;
- карусель 1080×1350 для поста.

## Что нужно
1. Подписка Screen Gallery и подключённый к агенту MCP-сервер Screen Gallery: `https://scrn.gallery/mcp`.
2. Агент, который умеет запускать код (Python 3 + Pillow, для PDF ещё reportlab). Без кода будет отчёт в чате.
3. Доступ из этой среды к scrn.gallery — оттуда скачиваются экраны.

## Установка
- Claude (claude.ai, десктоп): коннектор Screen Gallery в настройках коннекторов; скилл — Настройки → Возможности → Навыки → загрузить zip.
- Claude Code: `claude mcp add --transport http scrn https://scrn.gallery/mcp`; папку скилла — в `~/.claude/skills/scrn-flow-compare/`.
- Codex (CLI, IDE, приложение): `codex mcp add scrn --url https://scrn.gallery/mcp`, затем `codex mcp login scrn`; папку скилла — в `~/.codex/skills/scrn-flow-compare/`.
- Любой другой агент с MCP: подключите сервер по адресу выше и дайте агенту прочитать `SKILL.md` — это обычная инструкция, скрипты лежат в `scripts/`.

## Как пользоваться
Просто опишите задачу, например:

> Найди в Screen Gallery все сценарии с рецептами у доставок продуктов. Сравни по шагам, у кого какая фишка, и собери PDF.

> Сравни онбординг Т-Банка и Альфы, отчёт в чат.

> Что изменилось в переводе по СБП у ОТП за год? Сделай карусель.

Агент сам найдёт сценарии, предложит, что сравнивать, проверит цитаты на крупных экранах и соберёт результат. Дальше правьте как с дизайнером: «убери цены», «покажи кнопку в кадре», «переделай вывод».

Помните: если сценария нет в каталоге, это значит «не сняли», а не «нет в приложении».

Примеры: `assets/example-report.json` (PDF по рецептам), `assets/example-slides.json` (карусель).
