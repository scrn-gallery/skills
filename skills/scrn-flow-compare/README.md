# scrn-flow-compare — сравнение сценариев из Screen Gallery

Скилл для ИИ-агента (Codex, Claude и других, кто понимает формат SKILL.md): находит в каталоге Screen Gallery нужный сценарий у разных приложений (или у одного приложения в разных версиях), сравнивает по шагам как UX-аналитик и собирает результат в нужном формате:

- отчёт прямо в чате — со ссылками на сценарии и экраны;
- PDF — обложка, таблица «кто что умеет», страница на каждую находку со скринами и кнопкой «Сценарий в SCRN», итог;
- те же страницы отчёта картинками (JPG, горизонтальные, без кнопок) — для альбома в посте или презентации;
- карусель 1080×1350 для поста.

## Установка
Инструкции для Codex, Claude Code, claude.ai и других агентов: https://github.com/scrn-gallery/skills

Коротко: нужна подписка Screen Gallery, подключённый MCP-сервер `https://scrn.gallery/mcp` и агент, который умеет запускать Python (для PDF и картинок; без кода — отчёт в чате).

## Как пользоваться
Просто опишите задачу, например:

> Найди в Screen Gallery все сценарии с рецептами у доставок продуктов. Сравни по шагам, у кого какая фишка, и собери PDF.

> Сравни онбординг Т-Банка и Альфы, отчёт в чат.

> Что изменилось в переводе по СБП у ОТП за год? Сделай карусель.

Агент сам найдёт сценарии, предложит, что сравнивать, проверит цитаты на крупных экранах и соберёт результат. Дальше правьте как с дизайнером: «убери цены», «покажи кнопку в кадре», «переделай вывод».

Помните: если сценария нет в каталоге, это значит «не сняли», а не «нет в приложении».

Примеры: `assets/example-report.json` (PDF по рецептам), `assets/example-slides.json` (карусель).
